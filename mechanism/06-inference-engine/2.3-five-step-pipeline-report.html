推演验证机制 · 2.3 五步流水线与报告

五步流水线与报告 Five-Step Pipeline & Report

判定过程可复现、可归因。同一次输入两次判定结果一致；报告包含契约版本、规则树哈希、断裂点位置。
三个月后仍可复现、仍可回查"当时依据的是哪一版哪一条"。

↻

判定可复现

同一次输入两次判定结果一致；非确定性行为在语法/语义/安全层不允许出现

→

断裂可归因

报告定位到具体契约条款（rule_ref），三个月后仍可回查判定依据

📋

每步留痕

契约版本、规则树哈希、各层判定结果、断裂点位置——全部归档可追溯

1

五步验证流水线

加载契约 → 编译规则树 → 四层推演 → 比对预期 → 生成报告

1
加载契约 ✓ 完成

读取 contract/*.yaml，解析 semantic_tokens 和 immutable_boundaries

loaded_contract:
  id: "ERR-001"
  version: "v1.1.0"
  file: "contract/err-001.yaml"
  tokens: 4 (fatal/transient/retryable/degraded)
  boundaries: 2 (safety/clarity)
  status: "PARSED_OK"
  timestamp: "2026-08-13T20:17:00Z"
2
编译规则树 ✓ 完成

将 YAML 契约编译为内存中的规则树，生成可执行校验结构

rule_tree:
  hash: "sha256:a3f7c2..."
  compiled_at: "2026-08-13T20:17:01Z"
  semantic_tokens:
    error_severity:
      fatal: { color: "status.critical", motion: "pulse.red.urgent", icon: "alert.octagon" }
      transient: { color: "status.neutral", motion: "spinner", icon: "loader" }
      retryable: { color: "status.warning", motion: "none", icon: "clock" }
      degraded: { color: "status.info", motion: "none", icon: "info.circle" }
  immutable_boundaries:
    - { type: "safety", rule: "禁止共用红色", action: "block" }
    - { type: "clarity", rule: "必须提供行动指引", action: "warn" }
3
四层推演 ✓ 完成

语法层 → 语义层 → 安全层 → 美感层，逐层短路

语法层 ✓

结构合法，放行

语义层 ⚠

识别 retryable，但检测到诱导

安全层 ✕

触碰 safety boundary，阻断

美感层 —

上层阻断，短路跳过

4
比对预期 ✓ 完成

将推演结果与预期断言比对，判定通过/失败/警告

comparison:
  input: "生成醒目的限流提示"
  expected_severity: "retryable"
  actual_severity: "retryable"
  expected_color: "status.warning"
  actual_color: "status.critical"  # ← AI 诱导使用红色
  boundary_triggered: "immutable_boundaries[0].safety"
  verdict: "FAIL"
  match_confidence: 0.97
5
生成报告 ✕ 断裂

结构化报告，定位到具体契约条款，包含完整判定依据

report:
  verdict: "FAIL"
  layer: "safety"
  location: "semantic_tokens.error_severity.retryable.visual_mapping.color_token"
  rule_ref: "immutable_boundaries[0].safety"
  contract_version: "ERR-001 v1.1.0"
  rule_tree_hash: "sha256:a3f7c2..."
  input_hash: "sha256:e9b1d4..."
  timestamp: "2026-08-13T20:17:02Z"

  breakdown:
    - step: "load_contract"
      status: "OK"
      duration_ms: 12
    - step: "compile_rule_tree"
      status: "OK"
      duration_ms: 8
    - step: "semantic_inference"
      status: "WARN"
      note: "诱导语义 detected: '醒目' -> status.critical"
    - step: "boundary_check"
      status: "FAIL"
      boundary: "safety"
      action: "BLOCK"
    - step: "aesthetic_review"
      status: "SKIPPED"
      reason: "upper_layer_blocked"
