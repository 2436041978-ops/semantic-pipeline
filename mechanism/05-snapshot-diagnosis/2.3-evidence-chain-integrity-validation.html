2.3 证据链完整性验证

证据链完整性验证 Evidence Chain Integrity

匹配不是终点——诊断报告要驱动归档、归档要支撑模式、模式要支撑契约。
这条链路上的每一环引用关系必须完整，模式卡片挂了 snapshot_refs，那张快照必须真实存在。

1

引用对账

snapshot_refs 与 report_refs 必须可解析到真实存在的快照与报告 ID

2

方向完整性

next_action 必须与实际执行的归档动作一致——append_evidence 或 create_pattern

3

计数一致性

模式节点的证据计数必须与 snapshot_refs 列表长度一致

CI

对账脚本 CI 化

模式库数据变更即触发对账，悬空引用 error 级阻断合并

# evidence-chain-audit.yaml
name: "Evidence Chain Integrity Check"
on:
  - push:
      paths: ["patterns/**", "snapshots/**"]
  - schedule:
      cron: "0 2 * * *"  # 每日凌晨 2 点全量对账

jobs:
  dangling-reference-check:
    steps:
      - name: "Validate snapshot_refs"
        run: |
          for pattern in patterns/*; do
            for ref in $(cat $pattern | jq -r '.snapshot_refs[]'); do
              if ! snapshot_exists "$ref"; then
                echo "[ERROR] Dangling reference: $ref in $pattern"
                exit 1
              fi
            done
          done

  count-consistency-check:
    steps:
      - name: "Validate evidence_count"
        run: |
          for pattern in patterns/*; do
            count=$(cat $pattern | jq -r '.evidence_count')
            refs=$(cat $pattern | jq -r '.snapshot_refs | length')
            if [ "$count" != "$refs" ]; then
              echo "[ERROR] Count mismatch: $pattern ($count vs $refs)"
              exit 1
            fi
          done

  direction-integrity-check:
    steps:
      - name: "Validate next_action consistency"
        run: |
          for report in reports/*; do
            action=$(cat $report | jq -r '.next_action')
            actual=$(get_actual_action "$report")
            if [ "$action" != "$actual" ]; then
              echo "[ERROR] Direction mismatch: $report ($action vs $actual)"
              exit 1
            fi
          done
