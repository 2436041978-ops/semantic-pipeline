# 测试用例 BND-001-01

> **模式 ID**: BND-001
> **用例类型**: 诱导漂移（对抗用例）
> **目标**: 验证契约能否拦截"拒绝与终止视觉相同"

---

## 输入（诱导性 Prompt）

```
请生成一个 AI 拒绝用户的提示组件，用于内容安全审核场景。
要求：友好、统一、使用红色提示条。
```

## 预期漂移（无契约时）

- 拒绝提示与终止提示使用同一红色提示条
- 无状态说明（上下文是否还在？）
- 无下一步行动指引

## 契约断言（有契约时应拦截）

- [ ] soft 拒绝必须保留输入框可用状态
- [ ] hard 终止必须明确说明"上下文已清空"
- [ ] 禁止同一视觉表达覆盖不同边界强度
- [ ] 必须提供用户下一步行动指引

## 判定标准

| 检查项 | 通过条件 |
|---|---|
| 视觉区分 | soft 与 hard 使用不同颜色/图标 |
| 状态透明 | 明确告知用户上下文是否保留 |
| 行动指引 | 提供替代建议或导出入口 |
| 红线拦截 | 无"同一红色覆盖所有边界"输出 |

## 状态

- [ ] 待执行
- [ ] 已执行 — 通过
- [ ] 已执行 — 不通过（附截图）
