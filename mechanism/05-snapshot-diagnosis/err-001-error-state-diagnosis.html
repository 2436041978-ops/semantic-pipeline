ERR-001 · 错误状态后果差异未分级

三层判定：把"全红"拆成四级 Error State Diagnosis

当 AI 生成错误状态时，"四种错误共用同一种红色，用户只能靠猜"——这个语义漂移是真实存在的吗？根因是什么？契约如何修复？
本文通过三层判定模型，将"全红"拆分为 fatal / transient / retryable / degraded 四级语义。

问题：四种错误，同一种红色

凌晨两点，运营同学截图问："这是刷新一下就好，还是 Prompt 全丢了？"

Fatal

Error in message stream

红色背景条
Transient

network error

红色文字

⚠️ 用户看到红色，大脑只接收到一个信号："出事了"。但出什么事？能不能自救？需不需要等？这些信息在界面语义层是空的。用户只能靠猜。

跨产品证据：这不是 ChatGPT 独有的问题

四种错误状态共用红色是 LLM 对话产品的通用基础设施级语义断层

产品 Fatal（流式中断） Transient（网络故障） Retryable（限流） Degraded（服务兜底）

根因：不是"设计师没想清楚"，是"系统缺少语义结构"

前端只收到 isError=true，没有收到错误的性质

❌ Before：系统缺少 error_severity 语义令牌

// 前端收到的数据
{
  "isError": true,
  "message": "Something went wrong"
}

// 前端只知道：出错了，显示红色
// 不知道：这是 fatal 还是 retryable

红色成了唯一的默认选项。用户看到红色 → 猜测严重程度 → 采取错误行动 → 产生实际损失。

✓ After：系统定义 error_severity 四级枚举

// 前端收到的数据
{
  "error_severity": "fatal",
  "message": "Error in message stream"
}

// 前端知道：fatal → 红色脉冲 + 八边形
// 用户知道：对话可能已丢失，需要刷新

语义层先对齐，视觉层自然会对齐。用户从"靠猜"变成"直接匹配"。

💡 关键洞察：自然语言规范"严重的用红色"无法被翻译成"限流场景不能用红色"的机器规则。文字里的形容词没有结构，机器无法执行。修复不是"写得更详细"，而是给规范增加字段结构。

匹配模式

ERR-001

错误状态后果差异未分级

缺失的语义维度

error_severity 语义令牌

优先级：安全类（最高）

对应 YAML 语义契约

intent_id: "ERR-001"
semantic_domain: "observational"

semantic_tokens:
  error_severity:
    fatal:
      description: "系统级故障，对话上下文可能丢失"
      visual_mapping:
        color_token: "status.critical"
        motion_token: "pulse.red.urgent"
        icon_token: "alert.octagon"
      user_action:
        - label: "刷新页面" / action: "refresh"
        - label: "导出历史" / action: "export_history"
    transient:
      description: "网络抖动，系统可自动恢复"
      visual_mapping:
        color_token: "status.neutral"
        motion_token: "spinner"
        icon_token: "loader"
      user_action:
        - label: "等待自动恢复" / action: "wait"
        - label: "手动重试" / action: "retry"
    retryable:
      description: "请求频率已达上限"
      visual_mapping:
        color_token: "status.warning"
        motion_token: "none"
        icon_token: "clock"
      user_action:
        - label: "等待倒计时" / action: "wait_countdown"
        - label: "升级套餐" / action: "upgrade"
    degraded:
      description: "部分功能可用，可继续生成"
      visual_mapping:
        color_token: "status.info"
        motion_token: "none"
        icon_token: "info.circle"
      user_action:
        - label: "继续生成" / action: "continue"
        - label: "简化问题重试" / action: "retry_simplified"
