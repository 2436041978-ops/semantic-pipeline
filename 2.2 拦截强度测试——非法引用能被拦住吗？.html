3
不可变边界 violation_action 三档执行

违反 immutable_boundaries 时，按契约声明的 violation_action 执行三档策略。

block 阻断生成

直接阻断契约入库，返回修改建议。适用于安全类边界（如高危操作缺二次确认、致命错误用普通文字）。

{ "action": "block", "message": "违反不可变边界：高危操作必须包含二次确认", "suggestion": "在 semantic_tokens.destructive_action 中添加 confirmation_required: true" }
warn 警告放行

记录警告日志，人工确认后放行入库。适用于非致命降级（如文案语气偏离但语义核心正确）。

{ "action": "warn", "message": "文案语气偏离：建议使用 'Critical' 替代 '严重'", "requires_approval": true }
escalate 升级审核

自动创建审核工单，升级至人工审核队列。适用于边界模糊、需跨角色裁决的场景。

{ "action": "escalate", "message": "语义边界模糊：新场景 'data_retention' 未在字典定义", "ticket_id": "ESC-2026-0712-001", "assigned_to": "semantic-translator@team" }
