分级执行链路

输入场景："请求过于频繁，请稍后再试"
→ 关键词提取：429 / 频繁 / 限流 / rate limit
→ 模式匹配：ERR-001 · 错误状态后果差异未分级
→ 查询契约规则树 → error_severity.retryable
→ 级别输出：retryable（限流/流控，可自助恢复）
→ 约束组合：黄色 + 时钟图标 + 倒计时 + 升级入口
✓ 契约定义 retryable = 分级输出 retryable
越界

无命中场景：返回"未覆盖"

禁止把字典盲区变成错误决策依据

✓ 正确做法

输入："量子纠缠导致服务器坍缩"
输出：⚠️ 未覆盖场景 —— 未匹配任何已知模式，请使用快照模板工具提交反馈

❌ 错误做法（被禁止）

就近猜测：fatal —— 把字典盲区变成错误决策依据 → 误分级风险

状态

三种版本状态与失败判定

最新 / 滞后 / 无版本信息

✓ 最新版本

加载 = 契约库最新（v1.1.0 = v1.1.0）· 正常输出，无版本提示

⚠ 版本滞后

加载 v1.0.0 < v1.1.0 · 答案可给但附带滞后提示，时效显化

✕ 无版本信息

分级结果缺失版本声明 → 判定为验证失败，无法确认答案时效

2.3

降级策略

契约加载失败时怎么办？

降级

加载失败 → 字典静态查询

分级关闭但字典可查，禁止静默崩溃

① 契约加载失败

ERR-001.yaml 文件缺失 / 解析错误 / 网络不可用

② 触发降级策略

自动切换为字典静态查询模式（覆盖层 + 绑定 + 场景映射只读浏览）

③ 界面显式标注

"当前为降级模式：契约未加载，仅字典查询可用"

④ 字典查询可用

可浏览覆盖层目录、语义绑定、场景映射，但分级功能关闭

✓ 正常模式

ERR-001 v1.1.0 已加载
分级器完整功能
自动匹配级别
版本对账正常

⚠ 降级模式

契约未加载
分级功能关闭
字典只读浏览
显式标注降级状态

显化

禁止静默降级 + 生产推演

用户必须知道自己拿到的是完整分级还是降级查询

✓ 正确做法（显式标注）

⚠ 降级模式：契约未加载，仅字典查询可用。语义分级功能已关闭。您可浏览覆盖层目录和场景映射，但无法执行自动分级。

✕ 错误做法（静默降级 = 验证失败）

界面无任何降级标识，但分级结果基于过期/缺失的契约。用户误以为拿到的是完整分级，实际可能是错误答案。

生产环境推演
