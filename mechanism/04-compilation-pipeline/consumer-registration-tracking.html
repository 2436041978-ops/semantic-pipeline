契约消费追踪 · 2.1 消费点注册与追踪

消费点注册与追踪 Consumer Registry

YAML 契约编译为 4 种消费格式分发出去之后，谁在消费、消费了什么版本？
不是人查文档，而是机器自动追踪：每个消费点在注册时声明自己消费什么契约、什么版本、什么格式。

1

消费点必须注册

每个 Prompt 前缀、组件校验器、CI 规则在接入时必须声明消费契约 ID、版本、格式

2

版本声明嵌在产物头部

编译管线在每种消费格式头部自动嵌入版本声明，消费点加载时上报版本号

3

消费状态实时看板

追踪每个契约被哪些消费点引用、消费了什么版本、最后一次消费时间戳

1

契约编译：产物头部嵌好版本声明

Compile Pipeline · 一份 YAML → 4 种格式，每种头部自动嵌入版本

输入：ERR-001.yaml

intent_id: "ERR-001"
version: "v1.1.0"
semantic_domain: "observational"

semantic_tokens:
  error_severity:
    fatal: { ... }
    transient: { ... }
    retryable: { ... }
    degraded: { ... }

输出：4 种消费格式（头部嵌版本）

# === compiled/prompt/err-001.prompt ===
# @contract: ERR-001
# @version: v1.1.0
# @format: prompt_prefix
# @compiled_at: 2026-07-12T13:40:00Z

在生成错误状态界面时，必须遵守...

# === compiled/schema/err-001.schema.json ===
{
  "_meta": {
    "contract": "ERR-001",
    "version": "v1.1.0",
    "format": "json_schema"
  }
}

# === compiled/checklist/err-001.checklist.md ===




# === compiled/ci/err-001.stylelint.js ===
// @contract: ERR-001
// @version: v1.1.0
// @format: ci_rule

✓ 编译管线自动在每种格式头部嵌入版本声明，消费点加载时解析并上报

2

消费点注册：声明消费什么契约

Consumer Registration · 每个消费点接入时必须注册

消费点注册表

consumers:
  - consumer_id: "prompt-err-gen"
    name: "Error-State-Generator"
    type: "prompt_prefix"
    consumes:
      - contract: "ERR-001"
        format: "prompt_prefix"
    registered_at: "2026-06-15T10:00:00Z"

  - consumer_id: "ci-stylelint"
    name: "Stylelint-Semantic-Plugin"
    type: "ci_rule"
    consumes:
      - contract: "ERR-001"
        format: "ci_rule"
      - contract: "ACT-001"
        format: "ci_rule"
    registered_at: "2026-06-01T08:30:00Z"

  - consumer_id: "comp-alert-val"
    name: "Alert-Validator"
    type: "component_validator"
    consumes:
      - contract: "ERR-001"
        format: "json_schema"
    registered_at: "2026-06-20T14:00:00Z"

  - consumer_id: "designops-check"
    name: "DesignOps-Checklist"
    type: "checklist"
    consumes:
      - contract: "ERR-001"
        format: "checklist"
    registered_at: "2026-06-10T09:00:00Z"

注册字段说明

consumer_id 消费点唯一标识
type 消费格式类型（prompt/ci/checklist/schema）
consumes 声明消费的契约 ID 和格式
registered_at 注册时间戳，用于追踪接入时效
