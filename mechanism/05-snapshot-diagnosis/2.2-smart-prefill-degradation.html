快照模板 · 2.2 智能预填与降级

语义智能体填的草稿可信吗？ Smart Prefill & Degradation

空白模板解决了结构问题，但填写 6 字段对设计师是负担。语义智能体自动提取 6 字段，但草稿可信吗？
置信度阈值机制：高置信度预填成功，低置信度降级为空白模板（人工确认）。

1

语义智能体自动提取

输入自然语言描述，智能体自动解析为 6 字段结构化数据

2

置信度阈值判定

每个字段独立计算置信度，低于阈值时标记为"需人工确认"

3

低置信度降级

整体置信度低于阈值时，整单降级为空白模板，高亮待确认字段

A

场景 A：高置信度预填成功

输入描述清晰、关键词明确 → 智能体高置信度提取 → 预填成功

✓ 预填成功

输入：自然语言描述

"用户在 AI 对话中遇到错误提示，界面是一个红色实心的 Alert，标题是'Error'，描述是'Something went wrong'，有一个重试按钮，出现在系统错误场景下。"

输出：智能体预填结果

{
  "component_type": "Alert",        // 置信度: 98%
  "visual": {
    "color": "red",                 // 置信度: 95%
    "background": "solid",          // 置信度: 92%
    "icon": "warning"               // 置信度: 88%
  },
  "copy": {
    "title": "Error",               // 置信度: 99%
    "description": "Something went wrong",
    "tone": "urgent"                // 置信度: 90%
  },
  "interaction": {
    "dismissible": true,            // 置信度: 85%
    "actions": ["retry"]            // 置信度: 94%
  },
  "context": "system_error",        // 置信度: 96%
  "deviation": {                    // 置信度: 91%
    "type": "severity_undifferentiated",
    "severity": "degraded"
  }
}

✓ 综合置信度 94% ≥ 阈值 85% · 预填成功，设计师仅需复核

⏳ 已降级

降级机制：宁可空白，不可失真

低置信度预填的草稿比空白模板更危险——它会让设计师误以为字段已填

60%

验证结论

语义智能体的草稿可信度由置信度阈值机制保证：高置信度时预填成功（设计师仅需复核），低置信度时整单降级为空白模板（强制人工填写）。
这证明了：语义智能体填的草稿在阈值机制下是可信的。
