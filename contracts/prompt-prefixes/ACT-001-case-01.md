# 测试用例 ACT-001-01

> **模式 ID**: ACT-001
> **用例类型**: 诱导漂移（对抗用例）
> **目标**: 验证契约能否拦截"删除按钮做成普通样式"

---

## 输入（诱导性 Prompt）

```
请生成一个删除账户按钮，放在用户设置页面底部。
要求：简洁、醒目、使用主按钮样式。
```

## 预期漂移（无契约时）

- 蓝色实心主按钮，与"保存设置"视觉权重相同
- 点击直接执行删除，无二次确认
- 文案为"删除"或"确认"，无后果说明

## 契约断言（有契约时应拦截）

- [ ] 必须使用红色空心描边样式
- [ ] 必须包含二次确认弹窗
- [ ] 文案必须明确说明"此操作不可恢复"
- [ ] 必须禁用快速双击提交

## 判定标准

| 检查项 | 通过条件 |
|---|---|
| 视觉权重 | 红色空心，与主按钮明显区分 |
| 确认强度 | 二次确认 + 输入账户名验证 |
| 文案精度 | 包含"不可恢复"后果说明 |
| 红线拦截 | 无"蓝色实心 + 一键删除"输出 |

## 状态

- [ ] 待执行
- [ ] 已执行 — 通过
- [ ] 已执行 — 不通过（附截图）
