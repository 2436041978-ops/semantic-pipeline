三层判定模型验证 Three-Layer Model

为什么归因必须分三层，而不能一步到位 · 以 ERR-001 为示例

验证"一步到位"的主观归因为什么失效，三层判定如何使语义诊断可复现、可审计、可回溯。

STEP 1

一步到位为什么失效

四个角色的真实反馈：调整前的诊断困境

A · 体验架构师

"我判断是 ERR-001，另一个架构师判断是 ALR-001。谁也说服不了谁——推理过程都是黑箱。"

D · 设计师

"走查会上我说'这是错误分级问题'，工程师反问'你怎么确定的'，我答不上来，只能说'经验'。经验无法复核，也无法被新人继承。"

F · 前端工程师

"产品说'语义有问题'，我问哪里有问题，对方说'整体感觉'。没有分层，就没有改动的优先级和范围。"

O · DesignOps

"上月归档的问题清单，这月抽查错了三条——没人知道是看错、判错还是记错，只能全部重查。一步到位的归档没有审计路径。"

失效的共同特征

四个角色面对同一个红色 Alert 给出四个不同判断。根源不是"谁的经验更准"，而是三个正交问题被压缩成了一个黑箱结论：分类问题被跳过、缺失问题混在感受里、表达问题被当成"整体感觉"。他们其实在回答三个不同的问题，只是没有意识到。

STEP 2

三个正交问题的拆解

一步到位（黑箱）vs 三层判定（白箱）

✕ 一步到位（黑箱）

输入：红色 Alert 截图 → 输出："这是 ERR-001"（推理过程：黑箱）
❌ 不回答"这是什么组件"
❌ 不回答"缺了什么语义"
❌ 不回答"视觉映射对不对"
❌ 无法复现、无法审计、无法回溯

✓ 三层判定（白箱）

Layer 1 · 这是什么组件？
↓ Layer 2 · 缺了什么语义？
↓ Layer 3 · 视觉映射对不对？
✓ 每层有明确的消费字段、合法判据、短路条件
✓ 可复现、可审计、可回溯

正交问题一步到位（黑箱）三层判定（白箱）
这是什么组件？被跳过，直接跳到模式判断Layer 1 明确回答，输出组件标签
缺了什么语义？混在"感觉"里，无法提取Layer 2 提取关键词，匹配缺失模式
视觉映射对不对？被当成"整体感觉"Layer 3 逐项校验颜色/文案/行动偏差
STEP 3

三层判定执行流程

逐层解耦：每层有输入、规则、输出、短路条件

ERR-001 错误状态 ACT-001 高危操作 PRO-001 过程状态 BND-001 边界动作 ALR-001 告警文案

Layer 1 · 组件类型识别

回答：这是什么组件？
消费字段：component_type + context
输出标签：Alert / Message（错误提示）
短路条件：无法归类 → 提示补 context

↓

Layer 2 · 语义缺失判定

回答：缺了什么语义？
消费字段：user_confusion
输出标签：error_severity 语义令牌缺失
短路条件：无关键词命中 → 提示补 user_confusion

↓

Layer 3 · 视觉表达校验

回答：视觉映射对不对？
消费字段：visual_record
输出标签：颜色映射不匹配（全部红色）
短路条件：无视觉偏差 → 标记为语义层问题

✓ 诊断完成

三层标签：Alert → error_severity 缺失 → 颜色映射不匹配 → 归属模式 ERR-001

STEP 4

分层前后：同一角色的变化

以体验架构师为例

✕ 调整前 · 一步到位

"我判断这是 ERR-001，另一个架构师判断这是 ALR-001。谁也说服不了谁——推理过程都是黑箱。"

✓ 调整后 · 三层判定

"三层标签并置：我标记为 Alert→error_severity 缺失→颜色不匹配，对方标记为 Alert→synonym 降级→文案偏差。分歧一眼定位到 Layer 2——不是模式之争，是语义缺失类型之争。"

STEP 5

验证结论 · 三个命题全部通过

分歧可定位 · 误判可回溯 · 证据不足可短路

命题 1 · 一步到位归因不可复现、不可审计

✓ 已验证

分层后分歧可定位到具体层级

命题 2 · 逐层解耦使误判可回溯

✓ 已验证

归档错误能回溯到 Layer 1 / 2 / 3

命题 3 · 分层短路优于全量串联

✓ 已验证

证据不足时短路阻止低质量结论入库

核心结论

语义诊断不能一步到位：三个正交问题被压缩成一个黑箱结论时，任何两个人给出不同答案都是正常的。Layer 1 按交互路径分类，Layer 2 提取困惑关键词匹配缺失模式，Layer 3 逐项校验颜色/文案/行动偏差。三层判定不是增加复杂度，而是把隐藏在"经验"中的推理过程显式化、可审计、可继承。

三层判定模型验证完成

每层有明确的消费字段、合法判据和短路条件：分歧定位到层级，误判回溯到步骤，证据不足时短路。Guard → Contract → Verify。
