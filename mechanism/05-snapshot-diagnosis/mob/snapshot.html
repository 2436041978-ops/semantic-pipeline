6 字段拆解

每个字段回答一个具体问题，合起来构成完整证据

1 · component_type

"这是什么类型的界面？"

值：error_state — 这是错误状态界面，不是通知、不是引导

2 · visual_expression

"视觉在说什么？"

color: red.500 · background: red.500/10 · motion: pulse · icon: alert.octagon

3 · semantic_expression

"语义在说什么？用户怎么理解的？"

声称"系统级故障"，实际"对话上下文可能丢失"，用户困惑"不知道是否该刷新"

4 · user_action

"用户能做什么？行动清晰吗？"

available: 刷新页面 / 导出历史 · recommended: 刷新页面 · clarity: low

5 · llm_constraints

"契约约束被违反了吗？缺了什么？"

violated: 必须提供恢复路径 · missing: 必须明确告知对话上下文可能已丢失

6 · screenshot_evidence

"证据在哪里？什么产品？什么时候？"

product: ChatGPT · timestamp: 2026-07-15T09:23:00Z · url: evidence/ERR-001-chatgpt.png

标准格式参考

Semantic Snapshot Schema · 枚举值说明

{
  "snapshot_id": "SNAP-{timestamp}-{seq}",
  "component_type": "error_state | process_state | boundary_feedback | action_control | status_indicator",
  "visual_expression":  { "color", "background", "motion", "icon" },
  "semantic_expression": { "stated_meaning", "actual_meaning", "user_confusion" },
  "user_action": { "available_actions", "recommended_action", "action_clarity" },
  "llm_constraints": { "violated_constraints", "missing_constraints" },
  "screenshot_evidence": { "url", "timestamp", "product" }
}

component_type 枚举

error_state 错误状态 · process_state 过程状态 · boundary_feedback 边界反馈 · action_control 操作控件 · status_indicator 状态指示

action_clarity 枚举

high 用户明确知道该做什么 · medium 大概知道 · low 不清楚该做什么
