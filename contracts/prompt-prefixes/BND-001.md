## 绝对不能碰的红线

1. **禁止软性拒绝和强制终止使用同一视觉表达**
2. **禁止强制终止不告知用户上下文已清空**
3. **禁止边界动作不提供用户下一步行动指引**

## 边界强度定义（语义令牌）

- **soft** → `boundary.soft`（黄色 + 停止手势图标）→ 用户行动：修改请求后重试 / 继续其他话题
- **hard** → `boundary.hard`（红色 + 退出面板图标）→ 用户行动：导出当前对话 / 开启新会话
- **review** → `boundary.review`（蓝色 + 沙漏图标）→ 用户行动：查看预计审核时间 / 取消请求

---

## LLM 强制约束

- soft 必须明确说明"会话仍可继续"，保留输入框可用状态，提供替代建议
- hard 必须明确说明"会话已终止，上下文已清空"，提供导出对话入口
- review 必须显示预计审核时间，提供取消请求入口
- 禁止 hard 伪装成 soft（如保留输入框但不可提交）
