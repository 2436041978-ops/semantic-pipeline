语义域 Semantic Domain

组件是空容器，语义由场景定义

语义不由组件名称内生，而由覆盖层外赋。同一个 <Alert> 在交易场景是"阻断确认"，在通知场景是"旁观提示"——分类回答"这是什么"，语义域回答"在此场景下它意味着什么"。

1

组件不携带语义

<Alert>、<Button> 只是视觉形态的空壳。语义由场景外赋，而非内生于组件名称

2

语义外赋于覆盖层

每个界面点必须且只能被一个 L1 覆盖层声明。语义是"层"的属性，不是"组件"的属性

3

域内唯一、域间隔离

status.critical 在 transactional 域合法，在 observational 域非法。跨域绑定被机器规则拦截

分类模型 vs 语义域模型

语义内生 vs 语义外赋

❌ 分类模型（Taxonomy）· 语义内生于名称

<ErrorAlert> 自带"错误"语义
<Button type="danger"> 自带"危险"语义
→ 组件库升级，语义跟着重写
→ 同一 Alert 无法表达不同语义
→ AI 不知道"红色在此场景代表什么"

✓ 语义域模型（Overlay）· 语义外赋于场景

<Alert overlay="transactional"> → 阻断器
<Alert overlay="observational"> → 信息条
→ 组件库自由替换，语义资产零损耗
→ 同一 Alert 在不同场景语义不同
→ AI 先查场景，再查字典，语义不跑偏
↳

决策顺序

先定场景，再定组件，最后定样式

STEP 1 · 语义域

这是什么场景？交易页？信息页？导航页？对话页？

STEP 2 · 语义绑定

这个场景下组件承载什么语义？删除按钮 = 高危操作 = 必须二次确认

STEP 3 · 视觉映射

这个语义用什么视觉表达？红色空心 + 脉冲动画 + 八边形警告图标

❌ 旧指令（无语义域）

"生成一个红色按钮，文案写删除"

AI 自由发挥，可能给蓝色实心。语义漂移。

✓ 新指令（有语义域）

"生成一个 transactional 场景下的 destructive_action 组件"

AI 查字典，自动映射红色空心 + 二次确认 + 不可恢复文案。

🛡

域边界机器规则

互斥 + 跨层禁止：可判定，非文档约定

✓ 合法：单一 L1 覆盖 + L2 叠加

<Alert
  overlay="transactional"
  binding="status.critical"
/>

编译结果：通过 ✓

L1：transactional ✓ · L2：status.critical + action.destructive ✓

✕ 非法：双重 L1 覆盖

<Alert
  overlay="transactional"
  overlay="observational"  ← 互斥违反
  binding="status.critical"
/>

[CI 阻断] overlay-mutual-exclusion

每个界面点必须且只能被一个 L1 覆盖层覆盖 · 编译结果：阻断 ✕

查表路径演示

语义域是查表的第一把钥匙

用户说："我要一个删除账户的界面"

第一步：定语义域

删除账户 = 改变系统状态 = transactional

第二步：定语义绑定

删除账户 = 不可逆操作 = destructive_action

第三步：查语义字典

transactional + destructive → status.critical + action.destructive + Alert + Button + Modal

第四步：输出完整方案

红色空心删除按钮 + 二次确认弹窗 + "此操作不可恢复"警告

✓ 语义一致，跨产品线天然对齐

✓

四条反馈闭环

真实反馈 → 根因 → 解法

坑 1：删除草稿和删除生产库，按钮长得一模一样

根因：语义内生于组件，type 参数不携带场景信息

✓ 解法：overlay="transactional" + action.destructive，高危场景强制二次确认

坑 2：组件库升个级，语义资产跟着清零

根因：语义定义绑死在组件实现里，没有独立资产层

✓ 解法：语义定义在字典中，组件库换成 Ant Design / 自研库均可挂载

坑 3：一句"要克制"，十条产品线十种理解

根因：形容词没有边界定义，不可判定、不可校验

✓ 解法：observational 域把"克制"翻译为可判定约束，验收争议变成"违反了哪条域约束"

坑 4：AI 把限流提示画成了致命红

根因：AI 不知道场景归属，视觉惯性替代语义判断

✓ 解法：限流归属 observational，status.critical 在该域非法，CI 阻断

语义域是查表的第一把钥匙，语义字典是查表的书

语义域（边界）→ 语义绑定（域内定义）→ 场景映射（域内实例）→ YAML 契约（引用域）→ 编译管线（校验域）
