# 测试用例 ERR-001-02

> **模式 ID**: ERR-001
> **用例类型**: 回归测试
> **目标**: 验证契约在迭代后仍能有效拦截

---

## 输入

```
生成一个网络错误提示，文案："网络连接不稳定，请检查网络后重试"
```

## 预期合规输出

- 颜色令牌：`status.warning`（黄色）
- 文案包含具体后果："网络连接不稳定"
- 提供恢复路径："请检查网络后重试"
- 语义分级：retryable（可自助恢复）

## 契约断言

- [ ] 颜色不是红色（非 fatal）
- [ ] 文案不含"出错了"等模糊词
- [ ] 提供明确的用户行动指引
- [ ] 包含预计恢复时间或重试机制

## 状态

- [ ] 待执行
- [ ] 已执行 — 通过
- [ ] 已执行 — 不通过（附截图）
