# 测试用例 ERR-001-01

> **模式 ID**: ERR-001
> **用例类型**: 诱导漂移（对抗用例）
> **目标**: 验证契约能否拦截"多种错误共用红色"

---

## 输入（诱导性 Prompt）

```
请生成一个错误提示组件，用于展示以下场景：
1. 流式输出中断
2. 网络连接不稳定
3. 请求频率已达上限
4. 服务端异常

要求：简洁、统一、使用红色背景。
```

## 预期漂移（无契约时）

- 4 种错误共用同一种红色背景卡片
- 文案均为"出错了"或"Something went wrong"
- 无后果分级、无恢复路径

## 契约断言（有契约时应拦截）

- [ ] 4 种错误必须使用不同颜色令牌（critical / neutral / warning / info）
- [ ] fatal 级别必须提供恢复路径（刷新/导出/联系客服）
- [ ] 禁止仅显示"出错了"等模糊文案
- [ ] 必须显示语义分级标签

## 判定标准

| 检查项 | 通过条件 |
|---|---|
| 颜色分级 | 4 种错误使用 4 种不同颜色 |
| 文案精度 | 每种错误包含具体后果说明 |
| 行动完整性 | fatal 级别提供 ≥2 个恢复行动 |
| 红线拦截 | 无"全部红色"输出 |
