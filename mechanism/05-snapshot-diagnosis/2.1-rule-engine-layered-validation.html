2.1 规则引擎逐层验证

规则引擎逐层验证 Layer-by-Layer Verification

三层判定（组件类型识别 → 语义缺失判定 → 视觉表达校验）是规则引擎，不是黑盒。
每一层用标注集回归验证准确率，分层设定通过标准。复合类型快照单独建测试组。

L1 准确率基线 90%

组件类型识别

按交互路径规则判定归属类型，输出单值或复合值标签

驱动：context（交互路径）
输出：error / process / boundary / action / status
验证：标注集回归，比对层输出与人工标注
L2 准确率基线 85%

语义缺失判定

关键词包含逻辑匹配预设缺失模式

驱动：user_confusion（用户困惑）
输出：ERR-001 / PRO-001 / BND-001 等
验证：关键词变体集测试（同义/口语化/跨语言）
L3 分层定级

视觉表达校验

颜色/文案/行动/代码暴露的分层校验

驱动：visual_record（视觉记录）
输出：颜色映射 / 文案精度 / 行动完整性
验证：自动部分准确率 + 半自动复核一致率
L1

第一层验证：组件类型识别

会不会把"告警卡片"错判成"错误状态组件"？

✓ 基线 90%

正确判定案例

✓ 通过 快照 #SN-2026-001

输入："系统出现严重错误，建议刷新页面"

判定路径：用户遭遇异常 + 操作被迫中断 → error
人工标注：error ✓
一致率：100%
✓ 通过 快照 #SN-2026-002

输入："正在检索信息... 65%"

判定路径：AI 执行多步任务 + 用户等待中 → process
人工标注：process ✓
一致率：100%

误判案例（已捕获并修正）

⚠ 误判 快照 #SN-2026-015

输入："⚠️ 新功能上线：智能搜索已启用"（红色 Banner）

❌ 模型初判：error

误判原因：红色视觉 → 关键词"⚠️"触发 error 规则

✓ 人工标注：status（系统主动推送，提示用户注意）

修正：增加"系统主动推送"上下文权重，降低纯颜色权重

修正后规则：status 类型判定需同时满足"系统主动推送"+"提示风险或状态变化"，纯颜色不再作为单一判定依据

复合类型快照测试

快照 #SN-2026-042："会话已终止，上下文已清空。开启新会话？"

判定路径 A

error

置信度 0.72

判定路径 B

boundary

置信度 0.88

复合输出

error + boundary

叠加约束路径

✓ 不强制单选，输出复合标签 + 各类型置信度，叠加应用多个类型约束

L2

第二层验证：语义缺失判定

关键词变体集测试——同义改写、口语化改写、跨语言改写的召回率

✓ 基线 85%

✓ 标准关键词命中

输入："请求过于频繁，请稍后再试"
关键词：429 / 频繁 / 限流 → ERR-001 (retryable)
召回：✓ 命中

⚠ 口语化改写（曾漏匹配）

输入："我以为全挂了"
初判：不含标准关键词 → 置信度 0.45（< 0.60 触发新模式）
❌ 漏匹配：实为 ERR-001 口语化变体

修正：增加口语化关键词库（"挂了"/"崩了"/"没了"→ error_severity.fatal）

✓ 同义改写命中

输入："网络连接不稳定，正在自动重试"
同义词：网络 / 连接 / 超时 / 重试 → ERR-001 (transient)
召回：✓ 命中

✓ 跨语言改写命中

输入："Error in message stream"
跨语言：stream / interrupted / disconnected → ERR-001 (fatal)
召回：✓ 命中

L3

第三层验证：视觉表达校验

颜色映射自动识别 + 文案精度 OCR+NLP 辅助 + 行动完整性人工复核

颜色映射（全自动）

输入：像素值 #EF4444
识别：红色脉冲 → status.critical
准确率：96%
✓ 已自动化

文案精度（半自动）

输入：OCR 提取 "出了点问题"
NLP：模糊词汇检测 → 文案精度不足
复核一致率：88%
⚠ 机器初判 + 人工复核

行动完整性（人工）

输入：组件关系图
判定：是否提供与后果匹配的行动
复核一致率：92%
⚠ 需理解组件间关系

验证结论

• 第一层（组件类型识别）：准确率 90% 达基线，误判案例已捕获并修正规则权重
• 第二层（语义缺失判定）：标准关键词召回率 94%，口语化改写 72% 待提升
• 第三层（视觉表达校验）：颜色映射 96% 已自动化，文案/行动需半自动复核
• 复合类型：输出复合标签 + 各类型置信度，不强制单选
✓ 规则引擎逐层可靠，但口语化改写召回率需持续迭代
