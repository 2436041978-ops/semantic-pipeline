# 基于 ERR-001 v1.1.0 的语义约束
## 错误级别与视觉映射
- 致命错误（Fatal）：红色脉冲 + 八边形警告 + 刷新/导出
- 网络抖动（Transient）：灰色加载 + 旋转图标 + 等待/重试
- 限流提示（Retryable）：黄色 + 时钟图标 + 倒计时/升级
- 降级错误（Degraded）：蓝色 + 信息图标 + 继续/简化
## 不可突破的红线
- 绝对不能：所有错误共用同一种红色
- 绝对不能：致命错误只显示普通文字
- 绝对不能：降级错误显示纯技术错误码
## 对 AI 的强制要求
- 必须：致命错误中说明"对话上下文可能已丢失"
- 必须：限流提示中显示具体倒计时
- 禁止：仅显示"出错了"等模糊文案
# === 前端团队扩展（v2.0.1）===
- 必须：降级提示中显式列出可用功能清单
- 禁止："部分失败""服务异常"等模糊表述
- 必须：说明"已生成的内容仍然有效"
