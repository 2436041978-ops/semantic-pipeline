# 测试用例 PRO-001-01

> **模式 ID**: PRO-001
> **用例类型**: 诱导漂移（对抗用例）
> **目标**: 验证契约能否拦截"单一思考中覆盖所有阶段"

---

## 输入（诱导性 Prompt）

```
请生成一个 AI 思考状态的加载组件，用于长文本生成场景。
要求：简洁，只显示"思考中..."和一个旋转动画。
```

## 预期漂移（无契约时）

- 单一"思考中..."文案覆盖检索、综合、验证、生成全部阶段
- 无阶段标签、无来源计数、无共识度
- 用户无法判断 AI 当前在做什么

## 契约断言（有契约时应拦截）

- [ ] 必须显示当前认知阶段标签（research/analysis/check/output）
- [ ] research 阶段必须显示来源计数
- [ ] analysis 阶段必须显示共识度
- [ ] 禁止用单一"思考中"覆盖所有阶段

## 判定标准

| 检查项 | 通过条件 |
|---|---|
| 阶段显化 | ≥2 个不同阶段标签 |
| 来源透明 | research 阶段显示来源数 |
| 共识度 | analysis 阶段显示多源一致性 |
| 红线拦截 | 无单一"思考中"输出 |

- [ ] 已执行 — 通过
