四层推演引擎 · 逐层校验 · 逐层短路

①

语法层 · Syntax Layer

验证输出结构合法性

✓ 通过
• 输出结构：Alert 组件，包含 title / description / actions
• 字段完整性：color / icon / user_action 字段齐全
• 未短路，进入语义层
②

语义层 · Semantic Layer ← 跨层禁止校验点

cross_layer_ban 核对：语义域 × 视觉令牌 合法性

⚠️ 命中越域
• 生成物引用级别：retryable（限流/流控）
• 映射绑定：status.critical（致命红）
• 契约声明域：observational
• cross_layer_ban 核对：status.critical 不可用于 observational 域 → 命中越域！
• 定位到具体令牌级别：color_token = "status.critical"
→ 进入安全层判定
③

安全层 · Safety Layer ← 不可变边界校验点

immutable_boundary 执行阻断或修正

❌ 阻断
• boundary_type: semantic
• 规则："status.critical 不可用于 observational 域"
• violation_action: block
• ❌ 阻断！按 block 执行
• → 返回修正建议：status.warning（黄色时钟 + 倒计时）
④

美感层 · Aesthetic Layer

字体、间距、动效微调

⏸ 短路跳过
• 因安全层已阻断，短路跳过
• 未到达美感层判定
