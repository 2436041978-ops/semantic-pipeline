Layer 2 · PASS

语义令牌匹配

Token Matching · 将快照值与契约语义令牌比对

快照中的视觉与语义描述必须能匹配到字典中已注册的语义令牌，自由文本或字典外命名不得入库。

match: visual_record → 字典查表
  "红色脉冲 + 八边形图标"
  → color_token: "status.critical"   ✓ 已注册
  → motion_token: "pulse.red.urgent" ✓ 已注册
  → icon_token: "alert.octagon"      ✓ 已注册
result: PASS · 3/3 tokens matched
Layer 3 · PASS

不可变边界检查

Boundary Check · 检测是否违反 immutable_boundaries

快照内容不得违反契约声明的不可变边界（safety / clarity）。命中即阻断，防止"错误模式"被当作正常样本归档。

check: immutable_boundaries
  - safety:  "禁止所有错误状态共用同一种红色"
             未触发 ✓（本快照含分级信息）
  - clarity: "每个错误级别必须提供明确行动指引"
             通过 ✓
result: PASS

Layer 4 · PASS

归档一致性确认

Archive Consistency · 生成语义哈希，确认可追溯性

为通过前三层的快照生成语义哈希，写入归档记录——同一模式的后续快照可据此聚类、比对与回溯。

archive:
  semantic_hash: "sha256:9f2c…a41e"
  matched_pattern: "ERR-001"
  cluster: "错误状态后果差异未分级"
  dictionary_version: "v2.1.0"
  archived_at: "2026-07-12T10:24:00Z"
result: PASS · 可追溯，允许入库

只有全部通过的快照，才允许进入语义模式库

四层防线各守一段：结构合法（L1）→ 语义有典可查（L2）→ 不碰不可变边界（L3）→ 归档可追溯（L4）。低质量快照在入库前被拦截，模式库只沉淀合格品。Guard → Contract → Verify。
