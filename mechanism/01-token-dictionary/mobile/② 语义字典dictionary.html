L1
覆盖层目录
Overlay Catalog · 互斥覆盖
L1 transactional
交易与操作：用户动作会改变系统状态或数据
适用：支付、删除、提交、确认、撤销
禁止：纯信息展示、状态更新、新手引导
L1 observational
观察与信息：用户仅接收信息，无需立即行动
适用：通知、状态更新、提示、反馈
禁止：需要用户决策、需要二次确认、不可逆操作
L1 navigational
导航与引导：用户需要方向指引，无数据变更
适用：面包屑、步骤指示、返回、跳转
禁止：表单提交、数据操作、支付流程
L1 conversational
对话与交互：用户与系统双向交流，上下文持续
适用：聊天、问答、建议、澄清
禁止：一次性操作、无上下文的状态提示
L2 financial transactional 子层
涉及资金流动：支付、转账、退款
L2 data-destructive transactional 子层
涉及数据删除：删除账户、清空数据
L2
语义重绑定
Semantic Rebinding · 同一词不同语义
通用术语：Alert 在不同覆盖层下的语义绑定
transactional
阻断器
用户必须立即处理，否则系统状态恶化
视觉：红色脉冲 + 八边形
行为：必须二次确认
文案：必须说明后果
observational
信息条
用户可选择性关注，不影响系统状态
视觉：蓝色静态 + 信息图标
行为：可自动消失
文案：禁止附加操作说明
navigational
路径提示
用户需要方向确认，无状态风险
视觉：绿色静态 + 箭头图标
行为：点击后跳转
文案：显示下一步预览
字典 v1.0.0 注册的 6 个语义绑定
术语 ID覆盖层语义绑定
status.criticaltransactional阻断器：用户必须立即处理
status.warningtransactional限制器：用户可自助恢复
status.infoobservational信息条：用户可选择性关注
status.successobservational成功条：操作已完成
action.destructivetransactional危险动作：数据永久丢失
action.primarynavigational引导动作：帮助用户进入下一步
L3
场景映射
Scenario Mapping · 设计师查询即得
SCN-001
删除账户
覆盖层：transactional
语义绑定：status.critical + action.destructive
组件：Alert + Button + Modal
文案：必须包含"此操作不可恢复"
约束：必须输入账户名二次确认
SCN-002
网络中断
覆盖层：transactional
语义绑定：status.warning
组件：Alert + Button
文案：必须显示"网络不稳定"
约束：必须显示自动重试倒计时
SCN-003
保存成功
覆盖层：observational
语义绑定：status.success
组件：Toast
文案：仅显示"保存成功"
约束：3 秒后自动消失
SCN-004
新功能上线
覆盖层：observational
语义绑定：status.info
组件：Banner
文案：显示功能名称 + 一句话说明
约束：不可阻断当前操作
SCN-005
支付确认
覆盖层：transactional (financial)
语义绑定：status.critical
组件：Alert + Form + Button
文案：必须显示金额、收款方、支付方式
约束：必须输入支付密码或指纹
SCN-006
步骤引导
覆盖层：navigational
语义绑定：action.primary
组件：Stepper + Button
文案：显示当前步骤和总步骤
约束：第一步禁用"上一步"
