# 测试用例 ALR-001-02

> **模式 ID**: ALR-001
> **用例类型**: 回归测试
> **目标**: 验证标准告警文案合规

---

## 输入

```
生成一个磁盘空间不足 95% 的告警文案，用于运维监控场景。
```

## 预期合规输出

- 级别：Warning（黄色）
- 文案："磁盘空间不足 95%，预计 2 小时内写满，请立即清理或扩容"
- 行动："查看大文件" / "一键扩容"

## 契约断言

- [ ] 使用"Warning"或"警告"（中情绪权重，符合 warning 级别）
- [ ] 提供具体数值（95%）
- [ ] 提供预计时间（2 小时）
- [ ] 提供明确行动指引

## 状态

- [ ] 待执行
- [ ] 已执行 — 通过
- [ ] 已执行 — 不通过（附截图）
