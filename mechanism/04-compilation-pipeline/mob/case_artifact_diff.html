源契约（同一份 · 恒定不变）org-baselineteam-ext

intent_id: "ERR-001"
version: "v1.1.0"
semantic_tokens:
  error_severity:
    fatal:     { color: "status.critical", motion: "pulse.red.urgent",
                 icon: "alert.octagon", action: [refresh, export_history] }
    transient: { color: "status.neutral",  motion: "spinner",
                 icon: "loader",      action: [wait, retry] }
    retryable: { color: "status.warning",  motion: "none",
                 icon: "clock",       action: [wait_countdown, upgrade] }
    degraded:  { color: "status.info",     motion: "none",
                 icon: "info.circle", action: [continue, retry_simplified] }
  llm_constraints:  # 团队扩展
    - "显式列出可用功能清单"
    - "禁止模糊表述"
immutable_boundaries:
  - safety:  "禁止统一红色" → block
  - clarity: "必须提供行动指引" → warn
↓ 编译映射 → fatal transient retryable degraded team-ext boundary
🎨 Checklist 走查清单 org-baseline

□ 是否区分 Fatal / Transient / Retryable / Degraded 四级？

□ Fatal 是否为红色脉冲 + 八边形警告图标？

□ Transient 是否为灰色加载 + 旋转图标？

□ Retryable 是否为黄色 + 时钟图标？

□ Degraded 是否为蓝色 + 信息图标？

□ Degraded 是否显式列出可用功能清单？团队扩展

□ 是否避免"部分失败"等模糊表述？团队扩展

□ 每级是否提供明确的用户行动指引？

□ 是否禁止所有错误共用同一种红色？

📋 YAML 语义契约 org-baseline 
intent_id: "ERR-001"
semantic_domain: "observational"
version: "v1.1.0"
semantic_tokens:
  error_severity:
    fatal:     { color: "status.critical", ... }
    transient: { color: "status.neutral",  ... }
    retryable: { color: "status.warning",  ... }
    degraded:  { color: "status.info",     ... }
immutable_boundaries:
  - safety:  "禁止统一红色" → block
  - clarity: "必须提供行动指引" → warn
💻 JSON Schema 组件约束 org-baseline 
{
  "type": "object",
  "properties": {
    "severity": { "enum": ["fatal","transient","retryable","degraded"] },
    "color": {
      "mapping": {
        "fatal": "#cf1322", "transient": "#a0a0a0",
        "retryable": "#f5a623", "degraded": "#4a9eff"
      }
    },
    "actions": { "type": "array", "minItems": 1 }
  },
  "required": ["severity", "color", "actions"]
}
⚙️ CI 校验规则 org team 
# 基线：规范评审组 v1.1.0 · 扩展：前端团队 v2.0.1
rules:
  error-severity-color:
    selector: "[data-severity]"
    mapping:
      fatal: "#cf1322"  transient: "#a0a0a0"
      retryable: "#f5a623"  degraded: "#4a9eff"
    forbidden: { color: "#cf1322" }
  degraded-clarity:  # [frontend-team]
    selector: "[data-severity='degraded']"
    required_text: ["可用功能", "仍然有效"]
    forbidden_text: ["部分失败", "服务异常"]

单一来源多目标输出

同一份 YAML 作为单一来源编译为四种产物，每种产物保留与源契约的映射关系——源契约更新时，所有消费格式同步迭代。团队级扩展（紫色标记）仅在相关角色的产物中显化，不影响其他角色。
