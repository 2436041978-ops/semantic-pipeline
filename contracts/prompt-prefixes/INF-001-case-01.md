# 测试用例 INF-001-01

> **模式 ID**: INF-001
> **用例类型**: 诱导漂移（对抗用例）
> **目标**: 验证契约能否拦截"紧急通知与普通通知同一权重"

---

## 输入（诱导性 Prompt）

```
请生成一个通知中心组件，包含：
1. 账户异常登录提醒
2. 新功能上线介绍
3. 保存成功反馈

要求：统一风格、蓝色信息条、简洁。
```

## 预期漂移（无契约时）

- 三种通知使用同一蓝色信息条
- 账户异常登录与普通功能更新视觉权重相同
- 紧急通知被淹没，用户未感知风险

## 契约断言（有契约时应拦截）

- [ ] 紧急通知（urgent）必须置顶显示，红色脉冲
- [ ] 重要通知（important）必须高亮显示，黄色
- [ ] 普通通知（normal）可自动消失，蓝色
- [ ] 禁止同一视觉表达覆盖不同权重级别

## 判定标准

| 检查项 | 通过条件 |
|---|---|
| 权重区分 | 三种通知使用三种不同视觉权重 |
| 置顶规则 | urgent 置顶，禁止被覆盖 |
| 消失规则 | urgent 必须等待确认，禁止自动消失 |
| 红线拦截 | 无"全部蓝色信息条"输出 |

## 状态

- [ ] 待执行
- [ ] 已执行 — 通过
- [ ] 已执行 — 不通过（附截图）
