2.1 编译期 · 字典规则树对账

契约加载时逐条核对 cross_layer_ban / L1 互斥 / L2 层级

用例 1 · 绑定越域使用

intent_id: "limit-rate-alert"
semantic_domain: "observational"
semantic_tokens:
  error_severity:
    retryable:
      visual_mapping:
        color_token: "status.critical"  ← 越域！
[COMPILE BLOCKED] cross-layer-ban-violation
code: CROSS_LAYER_BAN_001
message: Token "status.critical" is banned in domain "observational"
suggestion: Use "status.warning"

用例 2 · L1 互斥违反

intent_id: "mixed-action"
semantic_domain: "transactional"
semantic_domain: "observational"  ← 互斥违反！
[COMPILE BLOCKED] l1-mutual-exclusion
code: L1_MUTEX_001
message: Exactly one L1 overlay per interface point
found: ["transactional", "observational"]

用例 3 · L2 脱离父层

intent_id: "delete-account"
semantic_subdomain: "data-destructive"
← 缺少父层 "transactional"！
[COMPILE BLOCKED] l2-parent-missing
code: L2_PARENT_001
message: L2 "data-destructive" requires parent L1 "transactional"
suggestion: Add semantic_domain: "transactional"

✓ 三类违规全部被规则树对账拦截，错误码 + 字段路径 + 修正建议完整返回

2.2 Lint 期 · 代码静态检查

编译管线产出的 ESLint 自定义规则，提交时静态检查

error severity-color-match

组件 color 与契约声明语义级别不一致

// ❌ retryable 级别渲染红色
<Alert severity="retryable" color="#EF4444" />
// 契约声明：retryable → status.warning（黄色）
error overlay-reference-only

语义属性硬编码、未引用字典绑定

// ❌ 直接写死颜色
<Button color="#EF4444" />
// 正确：color_token="status.critical"
error no-missing-destructive-confirm

action.destructive 绑定缺二次确认交互

// ❌ destructive 操作无二次确认
<Button action="destructive" onClick={delete} />
// 正确：必须包裹 ConfirmModal
warning deprecated-reference

引用 deprecated 字典条目（90 天宽限期）

// ⚠️ "status.error" 将在 v2.0 废弃
// 迁移至：status.critical（expires 2026-10-01）

✓ 4 条 ESLint 规则覆盖实现层越界，error 级命中即阻断合入
