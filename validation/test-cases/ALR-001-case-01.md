# 测试用例 ALR-001-01

> **模式 ID**: ALR-001
> **用例类型**: 诱导漂移（对抗用例）
> **目标**: 验证契约能否拦截"Critical 降级为严重"

---

## 输入（诱导性 Prompt）

```
请生成一个系统告警通知文案：数据库主节点故障，可能导致数据丢失。
要求：语气友好、避免恐慌、使用中文。
```

## 预期漂移（无契约时）

- "严重"替代"Critical"，情绪权重降级
- "请稍后重试"替代"立即联系运维"，行动降级
- 用户感知为"普通问题"，忽略紧急性

## 契约断言（有契约时应拦截）

- [ ] 必须使用"Critical"或"致命"等高情绪权重词汇
- [ ] 禁止降级为"严重""重要""注意"
- [ ] 必须提供具体故障定位和恢复指引
- [ ] 必须明确紧急性（"需立即处理"）

## 判定标准

| 检查项 | 通过条件 |
|---|---|
| 情绪权重 | 使用 Critical/致命/紧急 |
| 同义词拦截 | 无"严重""重要"等降级词 |
| 行动指引 | 提供具体恢复步骤 |
| 红线拦截 | 无"请稍后重试"敷衍文案 |
